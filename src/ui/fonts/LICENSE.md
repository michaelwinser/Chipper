# Bundled fonts

Both faces are self-hosted so the app works offline and from `file://` — a webfont CDN
would make first paint depend on the network, which the PRD's "works offline" promise
does not allow.

Latin subset only, taken from the Google Fonts CDN.

| File | Family | Licence | Source |
|---|---|---|---|
| `newsreader-latin.woff2` | Newsreader | SIL Open Font License 1.1 | https://fonts.google.com/specimen/Newsreader |
| `ibm-plex-sans-latin.woff2` | IBM Plex Sans | SIL Open Font License 1.1 | https://fonts.google.com/specimen/IBM+Plex+Sans |

The SIL OFL permits bundling and redistribution, including in a commercial product,
provided the fonts are not sold on their own and the licence travels with them.
Full text: https://openfontlicense.org/
